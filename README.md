## Trackmania Nations Forever Centering Tool (tmcnt)

Tmcnt is a tool for moving all blocks in a Trackmania map easily, without replacing blocks manually in the editor. 
It can be used either to shift a map to gain more space, or to automatically center a map in the buildable area, which really just looks better. 
It features a graphical user interface with basic movement options, and a map display to help visualise the change.
